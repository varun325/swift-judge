iOS decides whether an `https://` link opens your app using the `apple-app-site-association` file's `components`. Decode a simplified AASA: `{"applinks": {"details": [{"appIDs": [...], "components": [{"/": "/orders/*"}, {"/": "/admin/*", "exclude": true}, {"/": "/p/?"}]}]}}`. Patterns: `*` matches any run of characters, `?` exactly one; components are checked **in order** and the first match wins (an `exclude` match means "open in Safari"). Return `"app"` or `"web"` per URL path.
