A feed mixes item kinds: `{"type": "text", "body": …}`, `{"type": "image", "url": …, "width": …}`, `{"type": "poll", "question": …, "options": [...]}`. Decode into `enum FeedItem: Decodable { case text(String), image(url: String, width: Int), poll(question: String, options: [String]) }` by reading `type` first. Unknown types decode as `.unsupported(type)`. Return `"text: …"`, `"image <width>px"`, `"poll … (<n> options)"`, `"unsupported <type>"`.
