Syncing from a server often means **upserting**. `@Model final class Tag { @Attribute(.unique) var slug: String; var uses: Int }` — inserting a model whose unique `slug` already exists **updates** the existing row instead of duplicating it. Insert a `Tag(slug:, uses: 1)` for each incoming slug but first read the current `uses` so the count increments. Then page through tags sorted by slug with `fetchLimit`/`fetchOffset`, logging `"<slug>=<uses>"` per page (joined by `,`).
