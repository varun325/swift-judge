Swiftful's *Multi-threading with background threads and queues*. Before async/await, fan-out/fan-in used `DispatchGroup`: dispatch each item to a **concurrent** queue (`DispatchQueue(label:attributes: .concurrent)`) inside `group.enter()`/`leave()`, square it, and store results through a **serial** "lock" queue. Block with `group.wait()`, then return the results sorted plus `"items <n>"`.
