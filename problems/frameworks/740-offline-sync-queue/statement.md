Apps should keep working offline and sync later. Model a FIFO queue of pending mutations: `enum Mutation { case create(String), rename(from: String, to: String), delete(String) }`. Events: `create x`, `rename x y`, `delete x` (enqueue), `offline`, `online` (flush the queue in order while online; a mutation targeting a name the server doesn't have fails and is **dropped** with a log), and `status`. **Coalesce** before sending: a `create` followed by `delete` of the same item cancels both. Log each sent mutation as `"sent <mutation>"`, failures as `"dropped <mutation>"`, and `status` as `"server: <names sorted>"`.
