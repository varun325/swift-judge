A charting API sends points as **arrays**, not objects, inside a nested envelope: `{"data": {"series": [{"label": "A", "points": [[0, 1.5], [1, 2.0]]}]}}`. Decode to `struct Series { let label: String; let points: [Point] }` where `struct Point: Decodable { let x: Int; let y: Double }` decodes from a two-element array via an **unkeyed container**. Return `"<label>: <sum of y> over <count> points"` per series.
