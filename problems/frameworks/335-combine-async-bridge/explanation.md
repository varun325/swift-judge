`.values` turns any publisher into an `AsyncSequence`, so Combine can be consumed with `for await` — including `@Published` via `$property.values`. Breaking out of the loop cancels the subscription. **Timing trap:** with a *live* subject, the subscription starts only when the loop begins iterating, so values sent before that are missed (and a `CurrentValueSubject` replays whatever is current at that moment). This problem uses a finite publisher so the result is deterministic — an early version of it, built on a live subject, was flaky for exactly that reason.
