L16's multi-touch pattern: keep **committed** state (`zoom`, `pan`) plus **in-flight** gesture state (`@GestureState`) that automatically resets when the gesture ends. Rendered values = committed combined with in-flight. Events: `pinch <m>` (in-flight magnification), `drag <dx> <dy>`, `end` (commit whatever is in flight), `cancel` (in-flight resets without committing). Log `"zoom <z> pan <x>,<y>"` (rendered values, 2 decimals) after each event.
