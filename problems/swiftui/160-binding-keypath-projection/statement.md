When you write `$profile.name`, SwiftUI uses `Binding`'s **key-path dynamic member lookup** to derive a `Binding<String>` from a `Binding<Profile>`. Create a root `Binding<Profile>` over class storage, then derive `nameBinding = root.name` and `ageBinding = root.age`. Apply edits `name=<v>` / `age=<n>` through the derived bindings and return the root's final `"name age"` plus the number of times the root setter ran.
