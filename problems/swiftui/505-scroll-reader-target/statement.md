Swiftful's *ScrollViewReader to auto scroll*. A chat screen calls `proxy.scrollTo(id, anchor:)`. Given message ids (in order) and commands, compute the id to scroll to: `bottom` (last message), `top` (first), `unread <id>` (the first message **after** `<id>`, or the last one if `<id>` is last/unknown), `search <text>` (first id containing the text, case-insensitive). Return `"<id> @<anchor>"` (`bottom` → `.bottom`, others → `.top`) or `"none"`.
