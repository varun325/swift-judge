An `@Observable final class SignUpModel` backs a `Form` with `email`, `password`, `confirm` and `agreed`. Expose computed `errors: [String]` (in order: `"email"` if no `@`/`.` after it, `"short password"` if < 8, `"mismatch"` if password ≠ confirm, `"terms"` if not agreed) and `canSubmit`. After each edit (`email=…`, `password=…`, `confirm=…`, `agree`), return `"<canSubmit> [errors joined by ,]"`.
