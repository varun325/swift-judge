`PhaseAnimator` walks through a sequence of phases each time its `trigger` changes, then returns to the first. Model `enum Phase: CaseIterable { case idle, lift, spin, drop }` with a computed `scale` (`1, 1.2, 1.2, 1`) and `rotation` (`0, 0, 180, 360`). Each phase transition takes `durations[i]` seconds (i = target phase index − 1, looping). For `triggers` trigger changes, produce the timeline `"<t>s <phase> scale <s> rot <r>"` for every phase entered (t cumulative, 1 decimal), starting with `"0.0s idle …"`.
