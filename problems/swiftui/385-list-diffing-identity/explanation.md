With stable ids, a reorder is a **move** (the row keeps its state and animates) and an edited title is an **update** — without ids, both look like remove + insert, losing state. That's why `ForEach` needs `Identifiable` data, and why using array indices as ids causes glitches. Note that a diff is *a* minimal edit script, not *the* one: when `[1, 2, 3]` becomes `[3, 1, 4]`, calling either 1 or 3 "the mover" is equally short — the algorithm's choice is deterministic but arbitrary.
