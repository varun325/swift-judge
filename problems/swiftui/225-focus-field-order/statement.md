Swiftful's *@FocusState* and keyboard submit buttons. With `enum Field: CaseIterable { case username, email, password }` and `@FocusState var focused: Field?`, the submit button moves focus to the **next** field, and after the last field dismisses the keyboard (`nil`). Implement `next(after:)` / `previous(before:)` on `Field?` and apply actions `submit`, `back`, `tap <field>`, `dismiss`, starting unfocused (a `submit` while unfocused focuses the first field). Log the focus after each action (`"none"` for nil).
