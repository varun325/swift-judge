Swiftful's *Badges on TabView*. `enum Tab: String, CaseIterable { case home, search, inbox, profile }` with selection and a `[Tab: Int]` badge store. Events: `select <tab>` (selecting `inbox` clears its badge), `notify <tab> <n>` (adds to the badge), `logout` (select `home`, clear all). After all events return one line per tab `"<tab><*> <badge>"` where `*` marks the selected tab and badges of 0 show `-`.
