To animate two values at once, SwiftUI uses `AnimatablePair<A, B>`, which conforms to `VectorArithmetic` (`+`, `-`, `scale(by:)`). Implement a generic `func lerp<V: VectorArithmetic>(_ a: V, _ b: V, _ t: Double) -> V` as `a + (b − a) scaled by t`, and apply it to `AnimatablePair(start[0], start[1])` → `AnimatablePair(end[0], end[1])` for each fraction. Return `[first, second]` rounded to 3 decimals.
