`typealias` names a complex function type once. `lazy.compactMap { … }.first` runs validators only until the first failure. **Swift 6 gotcha:** a global `let` must be `Sendable`, and a plain function type isn't — so `[(String) -> String?]` at global scope is an error (*not concurrency-safe*). Marking the function type `@Sendable` promises the closures don't capture mutable shared state, which makes the array safe to share across threads.
