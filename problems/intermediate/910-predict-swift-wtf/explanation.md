Value semantics mean `b` is an independent copy; a family emoji is one `Character` but 8 UTF-16 code units; `Int8.max &+ 1` wraps to `-128`; `%` keeps the dividend's sign and `Double` needs `truncatingRemainder`. Arrays are `Equatable` but **not** `Comparable` — `[1, 2] < [1, 3]` doesn't compile, so ordering uses `lexicographicallyPrecedes`. `Int??` distinguishes "no value" (`nil`) from "a value that is itself nil" (`.some(nil)`). And binary floating point can't represent 0.1 exactly.
