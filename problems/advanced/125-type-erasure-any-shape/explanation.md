A protocol with associated types can't be stored in a homogeneous array as-is: `Uppercaser` and the Length→Stars chain are different types. Type erasure hides the concrete type behind a generic struct that forwards to a stored closure — the pattern behind `AnySequence`, `AnyHashable` and Combine's `AnyPublisher`. (Swift 5.7+ also offers `any Transformer<String, String>` with primary associated types.)
