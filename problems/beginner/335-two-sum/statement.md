Return the indices of the two numbers that add up to `target`, smaller index first, or `[]` if none. Solve it in **one pass** with a dictionary from value to index.

 ```swift
 twoSum([2, 7, 11, 15], target: 9)   // [0, 1]
 twoSum([3, 3], target: 6)           // [0, 1]
 twoSum([1, 2], target: 7)           // []
 ```
